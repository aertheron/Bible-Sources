# Selected lexical source data

This initial snapshot contains 606 upstream-derived records: 500 from STEP sources and 106 Open Scriptures lexical bindings/outlines. The records retain source entry IDs, extended identifiers, homonym distinctions, definitions where permitted, locators, hashes, licence and editing/coverage status.

Use `indexes/lexical-entry-index.json` to locate exact entries. A shared translation gloss is not enough to identify a lemma, and an entry's lexical range is not automatically the sense of a particular occurrence.

Full upstream datasets and pinned/hash-identified URLs are in `upstream_dataset_manifest.json`; this is an acquisition register, not a claim that all those files are published here. Full caches can be obtained separately from the original sources. TBESH definition/gloss prose remains excluded. The project's 50 enriched contextual word/theme studies are published as separate authored teaching material in [knowledge/word-studies](../../knowledge/word-studies/), with a [lookup index](../../indexes/word-study-index.json). The public MVP retrieves these studies and the selected lexical records; it does not claim an exhaustive lexicon or concordance.
