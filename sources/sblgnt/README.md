# SBLGNT source exports

The main text and apparatus are separate, byte-preserved user-supplied exports, with 27 book files each. The main-text files contain 7,939 verse rows. Copyright © 2010 Society of Biblical Literature and Logos Bible Software; edited by Michael W. Holmes. [Current publisher licence: CC BY 4.0](https://www.sblgnt.com/license/).

`text/` contains the main text, including editorial markers. `apparatus/` contains edition-comparison notes. The latter is not a complete manuscript-by-manuscript NA28/UBS5 apparatus. Book filenames and native reference labels are preserved. See the root attribution and preservation records for the modifications and hashes.
