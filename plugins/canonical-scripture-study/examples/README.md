# Small structured examples

variant-assessment.json uses the actual SBLGNT base text of Matthew 6:13 with pinned source evidence. It deliberately supplies no invented alternative or manuscript attribution. Passing it to evaluate retains that base provisionally; this is a contract example, not a claim that the verse has no variants.

fetch-handoff.json demonstrates the strict stage envelope with a small, verified source packet. Run validate-handoff to check its shape, scope and size. Source coverage and linguistic/interpretive correctness still require review.

Use the README commands for Dutch interlinear, Next, DSS paging and word-study retrieval. Model-produced translations and full study artifacts are not automatically published as new curated knowledge.
